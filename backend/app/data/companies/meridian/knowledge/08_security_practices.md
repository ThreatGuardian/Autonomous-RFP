# Security practices

## Secure supply chain
Equipment is procured only from authorised manufacturer distribution. Serial numbers are recorded at receipt, and tamper-evident packaging is verified before staging.

## Hardened configuration
Devices are delivered with a hardened baseline: firmware updated to the latest stable release, BIOS password set, secure boot enabled, full-disk encryption configured and endpoint protection installed where licensed.

## Firewall and network security
Firewall deployments follow vendor best-practice hardening with least-privilege rule sets, administrative access restricted to management networks, and logging forwarded to the client's SIEM where available.

## Background-verified engineers
All Meridian engineers who work on client sites are background verified and bound by confidentiality agreements.
