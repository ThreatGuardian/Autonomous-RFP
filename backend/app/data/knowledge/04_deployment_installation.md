# Deployment and installation

## Staging and imaging
Devices are staged at our Pune integration centre before dispatch. Staging includes BIOS configuration, asset tagging, OS image deployment, driver packs, security agent installation and a quality check recorded against each serial number.

## On-site deployment
Our deployment engineers unbox, install and hand over devices at the desk, migrate user data where required, and remove packaging for recycling. Deployment is scheduled around the client's working hours, including evenings and weekends for business-critical sites.

## Network implementation
Network projects follow a documented method: site survey, low-level design, pre-staging of switches, access points and firewalls, change-controlled cut-over and post-implementation verification with a signed acceptance test report.

## Data-centre commissioning
Servers, storage and power equipment are racked, cabled to agreed standards, labelled and commissioned. A commissioning report records firmware versions, configuration and burn-in results.
